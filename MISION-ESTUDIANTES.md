# QuickBite v2.5 — Misión QA

El equipo de desarrollo acaba de entregar QuickBite v2.5. La versión incorpora una nueva promoción de 10% de descuento. Su equipo representa QA y debe decidir si la versión está lista para liberarse.

## Misión 1 — Smoke Test
Tienen 5 minutos. Definan y ejecuten únicamente las pruebas indispensables para decidir si vale la pena continuar probando esta versión.

Registren: prueba, resultado esperado, resultado obtenido y PASS/FAIL.

## Misión 2 — Bug Hunt
Exploren la aplicación e intenten descubrir defectos. No se limiten al camino “normal”: prueben valores límite, cambios de cantidad, eliminación de productos, datos incompletos y diferentes combinaciones.

Para cada hallazgo documenten:
- Pasos para reproducirlo.
- Resultado esperado.
- Resultado obtenido.
- Severidad propuesta: baja, media, alta o crítica.

## Misión 3 — Clasificación
Para los casos encontrados, discutan cuáles podrían comprobarse mediante pruebas unitarias, integración, sistema o aceptación.

## Información de versión
En QuickBite v2.4, los pedidos con subtotal de Q100 o más tenían envío gratuito. El cambio anunciado para v2.5 fue la incorporación de la nueva promoción del 10%.

Pregunta final: ¿qué funcionalidades deberían volver a probar aunque desarrollo asegure que “solo se modificó Promociones”?
